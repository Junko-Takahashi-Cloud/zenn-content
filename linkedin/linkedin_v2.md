【長年温めてきた構想をテーマにしたWeb開発ポートフォリオ・第二弾】

事務職20年からエンジニアを目指す過程で作っている「スポーツボウリング場予約システム」の第二弾が完成しました。

■ 今回追加した機能
・初心者教室(全5回コース)の自動生成・個人/団体申込
・「一般利用」を教室修了者限定にする資格チェック
・クラウドファンディング特典(レーン貸し切り)の予約機能

■ 今回の学び
実装している途中で、「これは自分が本来考えていた構想と違う」と気づき、機能の位置づけを見直す場面がありました。作ったコードを無駄にせず、意味づけを変えて活かせたのは、AIと対話しながら開発を進めていたからこそだと感じています。

第一弾は複数のAIにレビューしてもらいながら進めましたが、第二弾はClaude一人との対話だけで、構想の整理からコードレビュー、Gitのブランチ運用まで完結させました。1つのAIと継続して対話することで、設計判断の一貫性を保ちやすいという発見がありました。

技術面ではGitのブランチ運用(feature branch → Pull Request → main)も実践し、V1のロジックを一切変更せず拡張のみで機能追加できました。
