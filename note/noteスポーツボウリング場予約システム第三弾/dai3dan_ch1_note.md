# スポーツボウリング場構想、第三弾がはじまりました

第一弾では、みなさんがボウリング場を予約できる仕組みを作りました。
第二弾では、初心者教室やクラウドファンディングの特典など、利用の形を広げてきました。

そして第三弾。今回作ろうとしているのは、これまでとは少し違うものです。

お客様が使う仕組みではなく、**スタッフが店舗を回すための仕組み**です。

## 「やりたいこと」がたくさんありすぎた

スタッフのログイン、その日の予約一覧、来店受付、レーンの空き状況、教室の出席管理、メンテナンス記録、売上の確認、決済の確認……。

数えてみると、やりたいことは思っていたよりずっと多くありました。これを全部いきなり作ろうとすると、きっとどこかで力尽きてしまいます。

だから今回は、コードを書き始める前に、「何を作るか」をちゃんと決めることから始めることにしました。

急がば回れ、というやつです。実際にAIと一緒に検討を始めるのは、次の章からです。
