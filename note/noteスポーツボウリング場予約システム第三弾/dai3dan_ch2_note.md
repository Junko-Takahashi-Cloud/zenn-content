# いきなり作らない。まずは4人のAIに聞いてみた

第三弾で何を作るか、実はすぐには決まりませんでした。

そこでまず行ったのは、4つのAI ── Claude、ChatGPT、Gemini、Copilot ── に、同じ質問を投げてみることでした。

「第三弾でお店を運営する機能を作りたいのですが、他に優先すべきことはありますか?全体像と論点を教えてください」

コードを書いてもらうためではなく、考えを整理するために聞きました。

## 4人分の意見を並べてみる

一つのAIの答えをそのまま鵜呑みにするのではなく、4つの答えを並べて、共通する部分・違う部分を見比べる。

正直、手間はかかります。でも「これから何を作るか」を決める一番大事な場面だからこそ、複数の視点を集めておきたいと思いました。

次の章では、この4人の意見からどんなことが見えてきたかを書きます。
