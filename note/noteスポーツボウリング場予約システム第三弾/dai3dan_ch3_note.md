# 第三弾は「お店を回すシステム」に決まりました

4人のAIの意見を並べて整理してみると、これまでの構想がどんな段階を歩んできたかが見えてきました。

- 第一弾:お客様が予約できる
- 第二弾:お客様がいろんな形で利用できる
- 第三弾:スタッフがお店を運営できる

第三弾でやりたいのは、管理画面をただ増やすことではありません。

営業日にスタッフが「今日は誰が来るのか」「どのレーンが空いているのか」「受付は済んでいるか」「教室の様子は」「決済はどうなっているか」を把握できて、お店を止めずに回せること。

それが第三弾の軸になりました。

第一弾、第二弾の上にもう一段積み上げる ── そんな位置づけです。
