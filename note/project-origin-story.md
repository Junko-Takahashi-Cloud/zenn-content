# 夢を形にする方法が、「技術」になりました。

子どもの頃、初めてボウリング場を訪れた日のことを、今でも覚えています。

その憧れは、大人になってサークル活動や競技ボウリングへとつながり、「もっと自由に練習できる場所があったらいいのに」という思いへ変わりました。

その気持ちは、やがて「スポーツボウリング場構想」という夢につながっていきました。

現在はPythonやWeb開発を学びながら、GitHubでポートフォリオを公開しています。

その中の一つが、スポーツボウリング場構想をテーマにしたクラウドファンディングサイトです。

これはホームページ制作の技術を示すポートフォリオであり、長年温めてきた夢を少しずつ形にしていくプロジェクトでもあります。

私にとって技術は、「作りたいものを、自分の手で形にするための手段」です。

これから予約システムの開発にも取り組み、その過程も記録として残していきます。
