# Zenn / Qiita / note / LinkedIn 記事シリーズ

このリポジトリでは、Zenn・Qiita・note・LinkedIn に投稿している技術記事、ITキャリアの歴史シリーズ、AI活用ノートを GitHub で一元管理しています。
Markdown で記事を管理し、GitHub によるバージョン管理を行いながら、各プラットフォームへ公開しています。

事務職20年からIT・AIエンジニアを目指す過程で得た知見や試行錯誤を、複数のプラットフォームで発信し、その記録をこのリポジトリにまとめています。

## 📚 コンテンツ

* IT歴史シリーズ（Zenn / Qiita / note / LinkedIn 並行投稿）
* AI活用メモ（Microsoft Copilot・Gemini・ChatGPT・Claude の比較）
* Excel VBA 実務改善ツール
